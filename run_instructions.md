# Run Instructions

This project was hosted with VITE, to be able to load textures without error. If you open index.html in the browser without running it with vite, the textures will not load.

### To run with vite:
- Open a terminal in the ./project_IN directory.
- Run the `npm run dev` command
- In the command's output, open the localhost link that looks like this `http://localhost:<port_number>` in your browser (Firefox and Chrome are supported, Safari has not been tested)
- ^C to quit vite
