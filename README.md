# run instructions

## option 1: on github pages

<a href="https://iannappi577.github.io/beach_tides/">>> Visit Here <<</a>

## option 2: localhost with VITE
- Open a terminal in the ./beach_tides directory.
- Run the `npm run dev` command
- In the command's output, open the localhost link that looks like this `http://localhost:<port_number>` in your browser (Firefox and Chrome are supported, Safari has not been tested)
- ^C to quit vite

### note: this project cannot be opened as static HTML on your localhost, because the textures will not load
