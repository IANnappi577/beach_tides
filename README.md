# beach_tides
webgl animated scene of a beach

# run instructions (deployed with VITE)
- Open a terminal in the ./beach_tides directory.
- Run the `npm run dev` command
- In the command's output, open the localhost link that looks like this `http://localhost:<port_number>` in your browser (Firefox and Chrome are supported, Safari has not been tested)
- ^C to quit vite

### note: this project cannot be opened as static HTML, because the textures will not load
